# Glossary

## AI Context Operating System

A lightweight Git-based structure for maintaining durable context used
by long-running ChatGPT Projects.

## ChatGPT Project

The ChatGPT runtime container that includes project instructions,
uploaded files, and conversations.

## Project Instructions

Small behavior-focused instructions pasted into the ChatGPT Project
settings.

## Source Documents

Curated Markdown files containing factual context intended for ChatGPT
retrieval.

## Upload Bundle

A generated or manually selected set of source documents uploaded into
the ChatGPT Project.

## Archive

Historical, raw, superseded, or snapshot material that should not be
treated as current by default.

## Living Document

A source document that is updated over time and represents current
state.

## Prompt

A reusable maintenance workflow stored as text, not a source of
canonical facts.
